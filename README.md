# KaaSniffer

KaaSniffer 是一个支持网络流量分析的工具，可用于监控和解析 TCP/UDP 流量，为网络应用与协议开发者提供便利。

## 功能特点

- **运行灵活**：支持跨平台运行，兼容 Windows、Linux 系统。
- **协议解析**：内置对多种常用网络协议的支持，如 HTTP、WebSocket 等。
- **可扩展性**：支持用户自定义协议。

## 快速开始

1. 克隆仓库：
   ```bash
   git clone https://github.com/surkaa/KaaSniffer.git
   ```

2. 进入项目目录，并根据文档安装依赖：
   ```bash
   cd KaaSniffer
   pip install -r requirements.txt
   ```

3. 启动 KaaSniffer，开始抓包分析。

   ```bash
   python main.py
   ```
